# Credits

## Egret2MAME

**Project, implementation and testing:** WiGGi

Egret2MAME started as a hobby project to make the TAITO EGRET II mini
Paddle & Trackball Controller practical to use with standalone MAME on
Windows.

The project includes hands-on controller testing, USB protocol
investigation, MAME input testing, installer validation, clean-system
testing and release documentation.

## Development assistance

**OpenAI ChatGPT**

Used as a development assistant for protocol analysis, code iteration,
debugging, documentation and release preparation.

## Special thanks

**Tomasz Moń and USBPcap contributors**\
USBPcap provides the Windows USB capture driver used by Egret2MAME Beta
0.815. The release repository includes the corresponding USBPcap 1.5.4.0
upstream source package and redistribution notice under `licenses/`.

**Jordan Russell and Martijn Laan**\
Inno Setup is used to build the Windows installer.

**Wireshark project and contributors**\
Wireshark was used during development for USB traffic analysis.

**MAMEDev and contributors**\
Official standalone MAME 0.289 for Windows was the primary emulator used
to develop and validate Egret2MAME. Arkanoid and Centipede were used as
the documented reference games for spinner and trackball setup.
