# Credits

## Egret2MAME

**Project, implementation and testing:** WiGGi0815

Egret2MAME started as a hobby project to make the TAITO EGRET II mini Paddle & Trackball Controller practical to use with standalone MAME on Windows.

The project includes hands-on controller testing, USB protocol investigation, MAME input testing, installer validation and clean-system testing.
